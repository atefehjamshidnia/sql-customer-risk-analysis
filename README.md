# Customer Loan Risk Analysis
This project analyzes Lending Club loan data (~2.26M records) to evaluate credit risk.

## 💻 Data Processing & SQL Code
The data extraction, cleaning, and SQL queries were performed using Python and SQLite. You can view the full code and query results in the `Lending_Club_Risk_Analysis.ipynb` file in this repository.
